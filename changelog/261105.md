### 变更内容

ACP 新增问答卡——agent 借权限通道提问（AskUserQuestion、多选题）按它给的选项原样作答，没答（超时或本轮结束撤卡）回 cancelled 不替用户挑；每条会话在工作区 .friday/sessions 落一份全量会话记录（目录自带 gitignore，不进 git、不混进本轮改动），「总结并新开」交接可换目标 agent，新会话首轮拿精简摘要+来源记录文件路径；审批入队与一轮收尾接通知中心 PostOnce 幂等系统提示，桌面壳新增打开系统通知设置深链与授权状态回查轮询；对话附件图片灯箱（气泡上方缩略图全图预览、←/→ 翻页、Esc 收起）；闪念笔记与待办正文均支持 Markdown，点卡片弹详情看全文；文件抽屉改动详情按轮次拉取并守护切会话/切项目竞态；品牌标统一为「白底圆角方块+中心黑点」几何（favicon、登录/欢迎页、外壳启动页与 gen-icon.py 同一套比例）；build-release.sh 的 $DMG_FOUND 引号小修。

### 修改原因

权限选项被压成批准/拒绝会把 agent 编码在选项里的答案丢掉；ACP 会话状态在 agent 侧，断线或上下文满后不可回溯，而投影时间线 agent 自己读不到；审批卡与收尾通知只出现在页面里，人切到别的窗口等于没发生；附件缩略图看不清原图；闪念列表正文截断后长内容无法查看；文件抽屉是页面级单例，缓存的轮次可能属于上一个项目或已被新一轮顶掉，慢回包会盖错面板；「五」字样 logo 与新图标几何不一致。

### 实现方式

问答卡按证据强度识别（questions 正文/工具名/选项 id 词元/自由选项），判不准宁可留在授权卡；会话记录整份重写永远等于当前时间线，删会话连带删、启动 GC 孤儿、快照遍历跳过 .friday；PostOnce 按 key 幂等、同一事件只提示一次，桌面桥失败只留档不重试；通知深链 URL 由外壳写死不接受前端传参，回查每 2 秒只读权限、最多 90 秒；灯箱走 /api/upload/:id 回读，附件丢失退回「📷 ×N」文字提示；交接换 agent 时不沿用模型与审批档位、回到工作区默认；抽屉拉取用代际号作废慢回包、轮次只认当前会话真实存在的 id。
