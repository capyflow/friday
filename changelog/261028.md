## refactor: 桌面外壳一体包、固定端口与凭据冷备（`80818ac942ca`）

- Commit: `80818ac942cafe98ca396a28334d63f138fb7cb8`

### 变更内容

内核改为随包 sidecar 直接运行并清理旧版 bin/friday；桌面启动固定端口 47831（被占用回退随机）；登录 token 增加数据目录原生冷备（auth_get/set/clear_token，仅主窗口与快捷键弹窗同源可读写）；补齐系统浏览器外链能力。

### 修改原因

外置内核没有更新通道且每次发版要同步两份二进制；随机端口让 localStorage 登录态每次重启失效；WebView 数据被清或端口回退时还需要一层凭据兜底；外链按钮缺少 ACL 会被 Tauri 拒绝。

### 实现方式

kernel_path 指向外壳同级 sidecar、remove_seeded_kernel 清理遗留、PREFERRED_PORT 探测后传给 --port；auth 命令原子写 desktop-auth-token（Unix 0600）；build.rs、palette/主窗口 capabilities 与生成的 permission 文件同步 ACL；更新 DESKTOP 文档与 Rust 测试。

## feat: 网页入口登录改为 JWT（`ab75926e8fa3`）

- Commit: `ab75926e8fa390ecee1cef1aec0a0db88ce0f0eb`
- 时间: `2026-10-28T18:17:57+08:00`

### 变更内容

登录与首装接口签发 HS256 JWT（7 天有效），前端保存并随每个请求携带；token 缺失/过期/被吊销时受保护接口返回 403，前端清 token 回登录页；图片回读允许 ?token=；桌面端启动从原生冷备回填 token。

### 修改原因

原来的内存会话 Cookie 重启即失效，也不方便多窗口、SSE 与无头请求显式携带凭据；需要一套可校验、可随密码变更失效的登录凭据。

### 实现方式

新增 auth.go（auth-key 落盘、密码版本 pv、退出吊销、403 auth 标记），login/setup 返回 token 并移除 Cookie 会话；web 端 auth.js 统一 localStorage 与原生冷备、api.js 统一 Bearer 头，SSE/上传/palette 逐处补头；测试辅助改 Bearer 并新增 auth 用例；同步 USAGE 与稳定性文档。
