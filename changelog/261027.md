## fix: ACP 握手超时误报为协议层错误（`84dbf4f52ee8`）

- Commit: `84dbf4f52ee8049d2b1bfa392c2d8478bd1fbb3b`
- 时间: `2026-10-27T01:39:43+08:00`

### 变更内容

internal/acp/proc.go 的 classifyInitError 增加 initialize 超时上下文参数，超时判定先检查 ictx.Err()；proc_test.go 补 SDK 包装超时的回归用例。

### 修改原因

Go ACP SDK 把超时包成不带 Unwrap 链的 *RequestError，errors.Is 认不出 DeadlineExceeded，npx 冷启动超过握手超时会误报成「initialize 被拒绝（协议层错误）」，误导排查方向。

### 实现方式

spawnAgent 把 ictx 传入 classifyInitError，判定顺序为进程退出 → 上下文过期 → 凭据关键词 → 协议层错误；超时文案补充 npx 首次下载这一常见原因。

### 涉及文件

- `internal/acp/proc.go`
- `internal/acp/proc_test.go`

## fix: 智能体对话图片链路——上传修复、粘贴发图与历史原图回显（`1f28026c1745`）

- Commit: `1f28026c17454545d64ce64a60e9019547364ea7`
- 时间: `2026-10-27T01:46:45+08:00`

### 变更内容

api() 封装对 FormData 原样透传；智能体页与主会话粘贴图片统一走 addImageFiles（非图片文件明确提示忽略）；发送后输入框预览即时清空、用户气泡直接渲染原图；「+」按钮改为与主会话同款的弹出菜单；后端 thread 历史记录附件 ID（Entry.Files）并新增 GET /api/upload/:id 回读图片。

### 修改原因

api() 会把 FormData 当 JSON 序列化成空对象，智能体页图片上传从未成功过（报「缺少文件字段 file」）；粘贴非图片文件打到图片接口产生误导性报错；历史只存图片数量，刷新后原图丢失只剩 📷×N 占位。

### 实现方式

api.js 识别 FormData 跳过 JSON 序列化与 Content-Type 头；粘贴只接 image/*；发送时把上传 ID 映射为 /api/upload/:id 服务端 URL 用于气泡展示（刷新不丢），对象 URL 即时释放；acp.Image 增 ID 随图片流转，appendTurn 落库 Entry.Files（旧数据仅数量时回退 📷×N 占位）；上传读取路由登录保护、ID 随机不可枚举、内容不可变允许长缓存。

## feat: 智能体线程选中即建会话拉能力清单（未发消息可切模型）（`4a436299812b`）

- Commit: `4a436299812be416bcba4ebb04217d5e60576143`
- 时间: `2026-10-27T10:38:29+08:00`

### 变更内容

智能体视图选中/新建线程时即拉取会话能力清单（模型/思考强度/审批模式），不再要求先发过消息；冷启动期间 composer 显示加载 chip，拉取失败 toast 报错。

### 修改原因

原实现只在 thread 已有 sessionId 时拉清单——能力清单只能建会话后获得，零消息新线程因此没有模型选项，而 Zed 新建会话后不发消息即可切换模型（Zed 在建线程时就建好了会话）。

### 实现方式

select() 去掉 sessionId 条件、无条件调 GET /options（后端会顺带拉起 agent 建会话，已有握手超时与并发槽位兜底）；capsLoading 状态渲染弱化呼吸样式的加载 chip，清单加载完成或确认为空即消失（不支持的能力仍缺席不渲染）；失败仅对当前选中线程 toast，切换线程竞态不误报；创建成功提示文案同步更新；docs/ACP-AGENTS.md 补加载时机说明。
