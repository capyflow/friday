## 对话暂停/继续与思考过程展示（zcode 风）

- 聊天发送键三态化：回复中变为**暂停**（点击即取消后端生成，token 即刻止损，已生成部分保留并标记"已暂停"）；暂停后变为**继续**（把原问题与已生成部分重新注入会话让模型接着完成，可反复暂停/继续，部分回答累加）；暂停期间输入新问题则按钮回到发送——点击即放弃上次任务、开启新对话。页面刷新后暂停现场经历史接口恢复，仍可继续。
- 新增**思考过程面板**（bot 气泡内可折叠，zcode 风）：实时展示思考型模型的推理内容（reasoning_content 透传）与 LLM 轮次/工具调用步骤（按请求 ID 订阅的过程事件 hub，运行中带 spinner，完成打 ✓/✕），回复结束自动折叠为"N 步"摘要。
- 实现：`agent.Resume`（框架在 ctx 取消时会回滚本轮，继续时重建上下文）、`web.Chat` 暂停状态机与 `POST /api/chat/stop`、`/api/chat/resume` 接口、SSE 协议新增 thinking/step/paused 帧；历史接口携带 paused 现场。钉钉/飞书/终端链路不受影响。
- 测试：假 LLM Provider 单测验证取消回滚与 Resume 上下文重建（会话消息数与内容断言）、事件 hub 按请求路由与退订；前端 vitest 覆盖三态按钮、暂停→继续、暂停后新开对话、刷新恢复。另以本地 mock 流式 LLM 做了完整浏览器 E2E：思考流式展示、暂停止损、继续接上原文、暂停期间新开对话、刷新恢复均通过。

## 多档权限模式（permissions.mode，参照 zcode）

- 新增全局权限模式 `permissions.mode`（设置页"权限模式"面板在线切换，热生效并写回 config.yaml）：`confirm`（默认，危险操作逐次网页批准）、`acceptEdits`（写文件/改 MCP 配置免审批直行，执行命令仍把关）、`fullAccess`（全部免审批，毁灭性命令黑名单仍强制拦截），解决 confirm 模式下逐次审批的繁琐。
- fullAccess 映射框架 full_access 模式（deny 黑名单在任何模式下仍拦截）；acceptEdits 经审批队列编辑免审标记放行 write_file/edit_file/mcp_edit 的内部审批，exec 策略不变。模式值规范化容忍 accept-edits / full_access / bypass-permissions 等写法，非法值启动即报错。
- 新增 GET/POST `/api/permissions`；修复 `Config.Apply` 未发布 Permissions 段导致切换后运行时快照不同步的问题。前端设置页新增权限模式面板（webdist 已重建），启动日志输出当前权限模式。
- 测试：模式规范化/校验/热写回保留注释、Checker 模式映射（fullAccess 白名单外放行且黑名单与附加 deny 仍拦截）、编辑免审开关对 write_file 与 mcp_edit 的实际放行；本机冒烟验证三档互切、重启持久化与非法值拒绝。前端存量通知测试失败与本次改动无关（干净工作区同样失败）。

## MCP 对话内管理工具（mcp_edit）

- 新增 `mcp_edit` 工具：agent 在对话中即可对 MCP 服务器增删改查（list/get/add/update/remove/restart），支持本地命令（stdio）与远程 URL（Streamable HTTP + 鉴权头）两种形态；写回 config.yaml 并经管理器热生效，下一轮对话即可使用新工具，无需重启服务。
- update 支持部分更新（只传要改的字段，其余保留；command/url 可互斥切换本地/远程模式），配置无变化时跳过写回；连接失败不回滚配置，错误保留在服务器状态中（list/get 可查，修复后 restart 或 update 即可）。
- 变更操作（add/update/remove）沿用 write_file 的审批模式：权限层直通 + confirm 模式下进网页审批（卡片展示修改前后配置）；查询与 restart 免审批。系统提示词补充 MCP 接入/排查指引。
- 装配调整：MCP 管理器提前到 Agent 首建前创建并注入工具依赖（此前首建时不可用）。管理后台"设置 → MCP 服务器"的网页编辑保持不变，与对话工具共享同一套校验与热生效链路。
- 测试：mcp_edit 单测覆盖远程/本地服务器全流程、参数校验、审批批准/拒绝、onChange 热生效链路；全量 `go vet` / `go test` 通过，本机冒烟启动与 admin MCP 接口验证正常。
