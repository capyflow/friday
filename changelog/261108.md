## feat(移动端): 服务器不在线不再甩浏览器报错页——改人话卡片 + 登录页可换服务器（`8ac5384c005d`）

- Commit: `8ac5384c005d2348b41dc6cf2bddf0b74c7a66b7`
- 时间: `2026-11-08T00:53:19+08:00`

### 变更内容

① 手机端「服务器不在线」时不再显示浏览器/内核自带的 net::ERR_CONNECTION_REFUSED 报错页：Android 壳拦下主框架加载失败，换成原生「服务器不在线」页（当前地址 + 重试连接 + 换个地址）；浏览器直访靠新增的 Service Worker 兜住上次缓存的页面壳，页面上是同一张卡片（说明 + 服务器地址输入框 + 扫码图标 + 重试连接）。② 登录页新增「服务器地址」输入行，默认显示当前连着的服务器，末尾带扫码图标——点开是扫码页（摄像头扫码，扫不了可手动输地址）：扫到电脑端「手机连接」的二维码，带一次性配对码的扫码即登录，纯地址的换成那台电脑；手输地址同样能换服务器。顺带修掉 eslint 缺 history/URLSearchParams 全局导致的 6 个 lint 报错（HEAD 上就红着）与 MobileThreads.vue 里一个没人用的 wsName。

### 修改原因

用户反馈「服务端不在线时应该告诉我服务器不在线，而不是直接展示这样的一个页面」，以及「登录页除了用户密码还要有输入服务器地址的，后面带扫描二维码的 icon」——原来的离线页是一串英文错误码，登录页也只有账号密码两栏，用户无法在手机上换一台电脑上的 Friday。

### 实现方式

壳（android/MainActivity.java）新增原生离线页（LinearLayout：标题/地址/说明 + 重试/换地址两个出口），在 onReceivedError 的主框架分支里切过去并把 WebView 藏起来——不藏的话 Chromium 的报错页会盖在原生页上面；加 JS 原生桥 window.FridayNative（isApp/getServerAddress/setServerAddress/connectTo/scanQrCode），网页侧封装见 web/src/mobile/native.js，浏览器直访时该桥不存在一律降级；壳侧扫出的结果经 window.__fridayScanCallback 回填网页。网页（web/src/mobile/）新增 server.js（地址归一化 + 扫码结果解析，配对码与普通地址分两种）、native.js（原生桥封装 + 跨端降级）、MobileScan.vue（扫码页：APP 内交壳的原生扫码页，浏览器用摄像头 + jsQR 逐帧解码，无权限时降级手输）、MobileServerRow.vue（地址输入行 + 末尾扫码图标）；启动失败态从一行红字换成「服务器不在线」卡片。Service Worker（web/public/mobile-sw.js）只缓存页面壳，接口一律不缓存——缓存带登录态的接口数据只会让用户看到别人的旧数据。地址换服务器只能整页跳（接口是同源相对路径，跨源调不动）：APP 里交壳换 origin 重载，浏览器里 location.assign。

## fix(构建): 恢复 webdist 占位文件并去掉未用的 FakeTerminal 解构（`e1f1c70f3311`）

- Commit: `e1f1c70f33114e5ec6ec65e41b5fcc81fce2c188`
- 时间: `2026-11-08T00:57:54+08:00`

### 变更内容

补回 internal/admin/webdist/.gitkeep（空文件），并去掉 web/tests/workspace-view.test.js 里只解构未被使用的 FakeTerminal。

### 修改原因

自 b15ade4 删掉 .gitkeep 后，webdist 下其余文件都被 .gitignore 逐个忽略，新克隆里该目录整个不存在，go:embed all:webdist 匹配不到任何文件而编译失败——CI 的 go test/go vet 步骤随之全红（main 上已连续 6 次推送失败）。FakeTerminal 则是 no-unused-vars 报错，让 npm run check 过不去。

### 实现方式

.gitkeep 是零字节占位文件，git 能跟踪空文件，go:embed 的 all: 前缀会把它算进嵌入集，编译恢复；FakeTerminal 在同文件第 38 行仍以 termMocks.FakeTerminal 引用，去掉多余解构即可，行为不变。
