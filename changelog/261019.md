## feat: 闪念页改为悬浮 + 弹窗编辑（Markdown 工具栏与独立标签按钮）（`f5dc10a2dd8d`）

- Commit: `f5dc10a2dd8dd1527f7483111aa1c43eaadf3abd`
- 时间: `2026-10-19T15:30:35+08:00`

### 变更内容

闪念页去掉页内 composer，右下角悬浮 + 打开编辑弹窗且创建与编辑共用同一编辑区；笔记正文上方新增 Markdown 格式工具栏（加粗/斜体/删除线/标题/列表/代码/链接），标签改由独立 # 按钮点选或回车新建，待办的截止/提醒按需展开；一并修掉深色下弹窗透出下层内容与悬浮加号不可见。

### 修改原因

页内 composer 常驻时间线顶部、与"记一条"这个动作割裂，且正文要手写 Markdown 语法、标签只能手打 #；深色下 `--card` 是半透明面被直接用作浮层背景，而前景写的 `var(--primary-fg, #fff)` 引用了不存在的令牌，回退成白色后与亮灰底同色。

### 实现方式

工具栏只在 textarea 选区上做纯文本增删（wrapAt/fenceAt/lineToggle/linkAt），落盘仍是 Markdown 源文故后端 parseTags 与小五读到的正文不变，二次点击按"选区两侧已有标记"原地取消包裹；待办按纯文本渲染所以不挂格式条；弹窗深色改用浮层惯例 rgba(24,24,24,.94)+blur(28px) 与遮罩 rgba(0,0,0,.6)，前景令牌统一为 --on-primary；重建内嵌产物并连跑两次构建确认幂等，npm run check 176 例与 go test admin/todo 全绿。

- `USAGE.md`
- `design-system/friday/MASTER.md`
- `internal/admin/webdist/index.html`
- `web/src/components/BlinkoView.vue`
