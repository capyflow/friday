## feat(界面): 正文支持 <media> 媒体块，agent 给的图片不再被当原文印出来

- 时间: `2026-11-17`

### 变更内容

agent 在回答里给的 `<media type="image" src="…" name="…" caption="…"/>` 现在
渲染成图片块——图内联显示，下面一行说明（name · caption）。不再把标签当普通
文字印在正文里。

- 本机绝对路径（`/tmp/xxx.png` 这类）走新的内联接口直接显示；
- http(s) 地址照直显示；
- 认不出来的类型（音视频、文件等）退成一行路径文字，不塞一个坏掉的 `<img>`；
- 本机图片块可点，点开进文件预览抽屉，和文件 chip 同一去处；
- 围栏代码块里的同名标签是示例文本，不当媒体块。

### 修改原因

Friday 的渲染管线里，marked 只把原始 HTML 转义成文本，媒体标签没有对应的一路：
标签被原样印在正文里，图文混排的效果全丢——agent 明明把截图路径给出来了，
人只能看到一串标签。

### 实现方式

- **后端**：新增 `GET /api/files/raw`（?path=，token 走查询参数）内联回传本机
  图片字节。只放行嗅探为 `image/*` 的文件（按内容嗅探，不认扩展名），带
  `Content-Security-Policy: default-src 'none'; sandbox` 与 `nosniff`——
  这个 URL 也能被直接打开，SVG 之类能带脚本，得锁死。
- `web/src/md.js`：先把媒体标签摘出来换成占位符（围栏代码块内的不动），HTML
  消毒完再用 DOM 构造把媒体块补回去——不走字符串拼接，没有注入面。
- `web/src/auth.js`：`mediaURL` 放行 `/api/files/raw`（`<img>` 带不了请求头，
  token 挂查询参数，与附件回读同一套口径）。
- `web/src/components/TimelineBlocks.vue`：媒体块里的本机路径接上 `@preview`。
- `web/src/style.css`：`.md-media` 版式（图 + 说明文字）。

## fix(界面): 回放时「答完之后的思考」不再吊在答案下面

- 时间: `2026-11-17`

### 变更内容

刷新或重启 Friday 后，之前那条孤零零挂在答案下面的「思考」行不见了——
回答重新回到最后。直播时的形状本来就对（思考在正文前），这次把回放也改成
同一口径。

### 修改原因

agent 答完还会接着想一段（实测 minimax-code 连着两轮都这样：最终回答发出去
之后又来了一段思考）。这段思考在投影里按到达顺序排在正文后面。

- **直播路径**（`pushThinking`）按「先思考后回答」把思考插到正文前面，
  所以流式时看不到那行吊着的「思考」；
- **回放路径**（`histBlocks`）把投影的块 1:1 映射，尾部那个思考块就留在
  答案后面——刷新一下就冒出来一行「思考」。

同一份数据、两条路径、两种形状。投影本身不动（留档按到达顺序是它的本分），
只在回放时把尾部思考挪到最后一个正文块之前。

### 实现方式

- `web/src/blocks.js`：`histBlocks` 增加 `trailingThinkBeforeText`——
  末块是思考且这一轮有正文时，把它挪到最后一个正文块之前。
- 测试：`web/tests/blocks.test.js` 加「回放与直播同口径」一组四条——
  同一串事件（思考/正文/工具交替，末尾接一段答完之后的思考）跑直播与回放
  两条路径，两边都必须以正文结尾。

### 涉及文件

- `web/src/blocks.js`
- `web/tests/blocks.test.js`
## fix(界面): 打字时对话不再上下跳

- 时间: `2026-11-17`

### 变更内容

在输入框里打字时，下面的对话不再跟着上下抖。输入框长高多少，对话就等量
上移多少（输入框缩回时等量回落），新回复始终露在外面。三个入口一起改：
主聊天页、智能体页、手机端 `/mobile`。

### 修改原因

输入框随打字自动变高 → 底栏变高 → 滚动区被压矮。贴底要等下一次内容更新
才补上，中间对话卡在旧位置，随后又被顶上去——看着像上下抖。实测输入框长高
113px 时，对话要等下一次流式输出才被顶上去 113px，删字再落回来。

### 实现方式

- 新增 `web/src/scrollkeep.js`：用 ResizeObserver 盯住底栏高度，变化当下
  就把内容底部重新贴到视口底部——对话跟着输入框平移，不攒到下一次贴底才
  突然跳。用户正在翻历史时不介入（底栏变高只是少露一点底部，不该把他拽回
  底部）。老 WebView 没有 ResizeObserver 时退化为不做任何事。
- `ChatView.vue` / `WorkspaceView.vue` / `MobileChat.vue`：各接一次，
  卸载时清理。
- 测试：`web/tests/scrollkeep.test.js` 五条（长高贴底 / 翻历史不动 /
  缩回不重复动作 / 无 ResizeObserver 退化 / 基线只记一次）。

浏览器实测（真实输入框 + 流式输出）：改之前打字时对话纹丝不动、底部 113px
被输入框盖住；改之后打字瞬间对话上移 113px、删除瞬间回落 113px，中间不再
有额外跳动。
