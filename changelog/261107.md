## feat(桌面): 外壳发现复用已有内核（attach 模式）与内核地址落盘（`f53953f0886f`）

- Commit: `f53953f0886f3f708ad06a9590dc06c7d4913a87`
- 时间: `2026-11-07T13:13:54+08:00`

### 变更内容

内核就绪后把服务地址原子落盘到数据目录 kernel.addr；外壳启动优先探测该地址，存活即 attach（不拉起 sidecar），失败回退原拉起路径；attach 模式加 10 秒存活轮询，连续两次失败走既有 kernel_dead 错误页。

### 修改原因

内核寄生在 .app 里，任何新入口（桌面壳重开、手机端）都可能拉起第二个内核进程，与已有实例争抢同一套数据文件；单内核多客户端要求外壳具备复用能力。

### 实现方式

Go 侧 writeAddrFile 原子写（仅 desktop/service 等数据目录语义明确的模式）；壳侧 probe_kernel 用 std TcpStream 裸 HTTP GET /api/session（零新依赖，与内核 waitReady 同一健康语义）；attach 不持有 child 句柄，quit_kernel 既有 child-None 守卫天然不触碰外部内核（真机验证：壳被杀后内核存活）。

### 涉及文件

- `cmd/robot/main.go`
- `desktop/src-tauri/src/main.rs`

## feat(桌面): 内核服务化——launchd 常驻服务与服务化启动链（`8be48f5c6855`）

- Commit: `8be48f5c6855368c54e6677a30c6ee7f2e79f023`
- 时间: `2026-11-07T13:28:48+08:00`

### 变更内容

内核新增 --service 模式与 service 子命令（install/uninstall/status/start/stop/restart，仅 macOS）；安装=自身二进制拷到数据目录 bin/friday+写 LaunchAgent plist+启动，plist 钉 WorkingDirectory 防 logx init mkdir panic，KeepAlive 崩溃自拉、开机自启；外壳启动链改为 确保服务→attach 已有内核→sidecar 兜底，并按版本比对升级服务二进制。

### 修改原因

单内核多客户端要求内核进程有唯一所有者；sidecar 随壳生死、壳被强杀内核陪葬，且多入口拉起多内核的风险需要一个常驻单例来根除。

### 实现方式

service 子命令自带 FlagSet 在 flag 解析前分流；--service 与 --desktop 共享 chdir+ensureUserPath 前置块，但无 /quit stdin 契约与 ppid 看门狗（均在 desktop-only 分支）；服务端口默认 45678 并在重装时从旧 plist 保号（避开 config 默认 8080 撞 Docker 的坑）；目标端口被占时只落盘不启动防崩溃循环；外壳移除 remove_seeded_kernel 旧清理（bin/friday 归服务所有）。

## feat(移动端): 配对 URL 携带叶子证书指纹（APP 扫码免确认信任）（`64a273392368`）

- Commit: `64a273392368bbc191e88af9eca78e3b84cbe367`
- 时间: `2026-11-07T16:10:14+08:00`

### 变更内容

/api/pair/info 的 url 追加 &fp=<叶子证书 SHA-256 hex>、响应加 fp 字段；新增 FingerprintPEM 帮助函数与单测（64 位 hex / 幂等 / 缺失与非 PEM 返空）。

### 修改原因

Android 壳 APP 扫码配对时把指纹一并拿到（二维码来自电脑屏幕，属带外可信通道），可直接 pin 免 TOFU 人工确认；浏览器侧只读 pair 参数不受影响。

### 实现方式

Start 挂载 TLS 门时对 leaf.crt 算指纹存 Server.leafFP；指纹解析失败返回空串，壳据此降级走 TOFU 人工确认。

## fix(移动端): APP 证书信任三连修——TLS 探测取指纹/隐形按钮拦截/GONE 替代 alpha（`2c8068a8b123`）

- Commit: `2c8068a8b1231f56aa3fa7422e6ab4ba112cc5df`
- 时间: `2026-11-07T19:53:10+08:00`

### 变更内容

onReceivedSslError 弃用 SslCertificate.saveState Bundle 黑科技（三星实测取不出字节→静默 cancel→白屏），改为后台对目标主机做真实 TLS 探测取叶子证书算指纹（trust-all 只取字节、3s 超时、按 host 缓存）；pin key 统一为 getHost()（不含端口，此前与查询 key 不一致导致重复弹窗）；加载失败浮层按钮从 alpha=0 改为 setVisibility(GONE)——alpha 0 的按钮依然拦截触摸，正好压在登录页用户名输入框上，点「用户名」实际弹回连接页（实测踩坑）。

壳的证书信任链路在三个环节各自断裂：指纹取不到、pin 对不上、隐形按钮抢触摸，任一都表现为白屏/弹回。

### 实现方式

probeFingerprint 用 SSLSocket(trust-all) 握手取 getPeerCertificates()[0] 算 SHA-256；探测期间 handler 挂起加载不丢事件；build.gradle 显式开 buildConfig（AGP 8 默认关闭，debug 判断需要）。
