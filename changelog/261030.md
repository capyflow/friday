## feat: 工作区项目记忆（按工作区共享并随首轮注入）（`4130984c656e`）

- Commit: `4130984c656e75bb77c665908840f52afeaa48fe`
- 时间: `2026-10-30T16:04:04+08:00`

### 变更内容

长期记忆页新增 scope 归属：空串仍是用户级全局 wiki，工作区 ID 归入该工作区的项目记忆。新增 /api/acp/workspaces/:id/memory 增删改查，智能体抽屉加「项目记忆」标签页，会话消息行加「记到项目记忆」按钮；首轮工作区说明追加 [Friday 项目记忆] 摘要，摘要指纹计入「说明是否需要重发」的判断。

### 修改原因

仓库级约定（用 pnpm、验收跑 npm run check）写进用户全局记忆会污染其他工作区，写进仓库文件又要用户管 git；同一工作区换 agent 或换新会话都得重新交代一遍。按工作区隔离后 A 仓的约定不会出现在 B 仓，新会话自带背景。

### 实现方式

memory.WikiStore 用 scope 过滤读写（SaveScoped/ReadScoped/DeleteScoped/PagesScoped/SearchScoped/DigestScoped/CountScoped），frontmatter 落盘 scope 保证重启后归属不丢，原全局方法退化为 scope 空串的包装；manager 经 SetMemory 注入存储，workspaceBrief 用 DigestScoped(workspaceID, 4, 1200) 取摘要拼进指纹，摘要变化后新会话会重新下发；工作区没有记忆页时不注入空段落。
