# 261110 变更记录

## docs: AGENTS.md 固化打包签名要求，README 增打包必读提示

- 时间: `2026-11-10`

### 变更内容

新增仓库根 `AGENTS.md`（给 AI 助手与新成员的工作须知），把「每次打包前必读
desktop/README.md 的 macOS 正确打包流程」固化为最高优先级条目：正式分发包必须
Developer ID Application 签名 + Apple 公证（`--macos-release`），禁止把 ad-hoc
测试包发布到 GitHub Release；打包前用 `security find-identity -v -p codesigning`
确认证书，产物必须过 `verify-macos.sh` 验收才能上传。README 的「手机端」之后
新增「桌面打包与发布（重要）」一节指向同一流程。另把本机运行时文件
`auth-key`（内核 JWT 密钥）与 `node_modules/` 加入 .gitignore。

### 修改原因

0.5.1 发布时本机没有 Developer ID 证书，包仍是 ad-hoc 签名。打包签名要求此前
只写在 desktop/README.md 深处，代理/新人凭记忆打包容易跳过；用户要求在 README
或 AGENTS.md 层面重点说明，保证每次打包都先看文档。

### 实现方式

AGENTS.md 分「打包与发布」与「其他约定」两段：前者列四条硬性检查（Developer ID
签名、禁发 ad-hoc、证书预检、verify-macos.sh 验收），后者收编发版速查（纯
vX.Y.Z tag、三资产、--clobber）与既有约定（changelog 分主题、auth-key 不入库、
45678 开发端口、worktree 预检）。README 用一节短文指向 desktop/README.md 锚点
与 AGENTS.md，不复制细节避免两处漂移。
