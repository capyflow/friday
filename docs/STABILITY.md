# 稳定性与故障恢复

2026-10-10 的修复覆盖 Markdown 渲染、账号加载、持久化、配置热更新、会话清除、聊天附件、审批和提醒投递。

## 启动与账号

- 本地/桌面默认监听 `127.0.0.1`。远程部署通过 `admin.host` 或 `--host` 明确指定地址；桌面模式强制本机监听。
- 首次没有账号文件时保留默认账号兼容行为。远程使用时预置 `FRIDAY_ADMIN_USERNAME` 和 `FRIDAY_ADMIN_PASSWORD`，或配置 `admin.username/password`。
- 已有账号文件损坏、无法读取、哈希无效或为悬空链接时，启动报错并保留原路径，不会写入默认密码。恢复有效的原账号文件/备份后重启；启动预置凭据不会覆盖一个无法验证的账号文件。
- 占用端口现在同步返回启动错误，不再打印就绪后才发现无法监听。

## 数据与配置

- 任务和待办文件损坏/不可读时拒绝空数据覆盖；保存错误反馈到接口与模型工具，失败保留上次成功提交的内存与文件。
- 原子保存检查 Write/Sync/Close/rename 错误。不存在的自定义父目录需要事先创建。
- 模型/人设热更新先构建和写回成功，再发布运行时快照；失败继续使用旧配置与旧 Agent。
- 配置读取使用独立快照，配置文件的读-改-写串行化。MCP 配置保存失败不改变运行状态；服务器连接错误仍显示具体失败信息。
- 清除上下文等待同会话的在途请求结束并落盘，然后清除会话和归档。失败返回错误，不再宣称成功。前端在发送期间禁用清除操作。

## 提醒与通知

- 生产入口使用 `NewReliableEngineFile`：任务先写入 `notifications.json`，成功后才推进次数/移除单次任务。入队或任务推进保存失败保留原计划，并幂等重试。
- 旧任务文件缺少 `next` 时先原子保存迁移后的计划时刻，再开始调度；迁移失败停止启动，避免重启改变同次触发的去重键。
- 循环/多次任务保存下一触发时刻，重启保留计划；停机期间错过的重复周期按原锚点追到下一未来时刻，单次过期任务立即补入队。
- 启用网页后，通知页显示正文、待处理/处理中/已送达/失败/静默状态及送达位置。关闭网页且没有真实输出通道时明确失败，不会计为已送达。
- 智能任务结果先持久化；已成功保存的结果和已确认记录的通道不会重复执行。自动重试最多 5 次，退避 2/4/8/16 秒；失败后可在通知页手工重试。
- `processing` 通知在重启后恢复为待处理。静默任务保留记录但不发送到外部通道。
- 发送到第三方通道与本地落盘无法做跨系统原子事务：若远程已经接收而成功确认尚未落盘时进程退出，恢复可能重复投递。智能任务已调用工具但执行结果未成功保存时也有同类窗口，恢复可能再次执行；对非幂等工具应使用审批并核对失败前的执行轨迹。本实现采用至少一次语义与已确认状态去重，不承诺跨系统严格仅一次。
- 通知历史完整保存到文件，页面展示最新 100 条。桌面系统弹窗和浏览器通知权限尚属后续产品能力。

通知接口（与其它后台接口一致，需要登录 Cookie，响应使用 `body` 包装）：

| 接口 | 行为 |
|---|---|
| `GET /api/notifications` | 获取最新通知及投递状态 |
| `POST /api/notifications/:id/retry` | 失败通知重新排队，保留已确认成功通道 |

## 前端

- Markdown 链接/图片 URL 校验、属性转义和 DOMPurify 白名单清洗共同处理不可信内容。
- 计划/目标模式可以发送；它们当前是文字意图提示，不承诺后端强制计划确认流程。
- 请求失败保留文本、模式和图片草稿；附件 URL 在对应消息/草稿清除或组件卸载时才释放。
- 发送和清除时防重复操作；卸载取消流式请求，过时的历史/审批响应不会覆盖新状态。
- 审批成功后才移除卡片；失败保留卡片供重试，处理期间防重复提交，退出登录清理旧审批。
