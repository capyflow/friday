日期：2026-10-10。基线：已完成的安全、持久化、并发、聊天、审批、通知和 Docker 稳定性修复。
这里的 P0 指下一版本优先交付范围，按下列顺序实施。

## P0-01 首次配置与模型连接诊断

- [ ] 提供首次配置引导，完成管理员账号、模型接口、模型名称和密钥设置。
- [ ] 增加显式的「测试连接」操作，展示实际可用状态与文本/图片能力。
- [ ] 对无效密钥、模型不存在、超时、额度不足和接口不兼容给出可操作的错误提示。

验收：全新数据目录启动后，用户通过界面完成配置并成功对话；错误密钥不能显示为连接成功。
测试凭据由用户在本地提供，诊断结果和日志不回显密钥。

## P0-02 后台驻留与主动提醒

- [ ] 桌面版支持托盘驻留，关闭窗口与退出应用的行为明确。
- [ ] 接入系统通知；网页通知页增加未读提示和已读状态。
- [ ] 支持「稍后提醒」，并明确记录原通知与新提醒的关系。

验收：应用驻留时切到其他应用仍能收到到期提醒；关闭窗口不会漏提醒；权限被拒时显示可用的替代入口。
明确退出后，下次启动按既定停机补偿规则恢复任务，不重复生成同次触发记录。

## P0-03 任务编辑、暂停与恢复

- [ ] 支持修改未来任务的内容、触发时间、周期和投递通道。
- [ ] 支持暂停/恢复，显示状态和下一触发时刻。
- [ ] 执行记录关联到原任务，便于查看触发、执行及投递结果。

验收：暂停后不触发，恢复后计划准确；编辑和暂停状态跨重启保留；保存失败不改变原计划。
修改、重启与补偿触发保持去重，已开始执行的任务有明确状态反馈。

## P0-04 待办截止时间与提醒关联

- [ ] 待办增加截止时间，并支持创建关联提醒。
- [ ] 修改截止时间同步调整关联提醒。

验收：「明天前交房租」能形成带截止时间的待办和提醒；勾选完成后不会继续触发未来提醒。
关联信息跨重启保留；任一步保存失败能回滚或明确提示需要恢复。
