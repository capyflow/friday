# P0 使用与验收

本轮实现首次配置与模型诊断、系统通知与驻留、任务管理以及待办提醒联动。真实模型和外部通道联调按用户选择延期；实现已通过模拟服务和隔离数据验证。

## 首次设置与模型诊断

直接启动服务时，真正不存在的 `config.yaml` 会生成无密钥的本机初始配置；已有配置、损坏文件和悬空链接都不会被覆盖。首次账号文件会保存待初始化状态，不启用默认密码。

本机网页只创建管理员账号；模型接口、模型名与 API Key 在「设置 → 模型」里填写，首次向导不再引导配模型。远程/Docker 部署通过 `FRIDAY_ADMIN_USERNAME` / `FRIDAY_ADMIN_PASSWORD` 预置账号，公开初始化接口只允许原始连接来自本机且 Host/Origin 正确。

「测试连接」实际发送少量文本，可选发送1x1测试图片；分别显示文本可用、图片输入已接受、不支持或未验证。未发起图片测试不推断视觉能力；测试输入不保存配置，表单改变后诊断结果失效。

错误提示区分鉴权、模型/接口不存在、额度/限流、超时/网络与响应不兼容。更换完整 API 地址时须填写该目标的密钥，不能沿用旧目标的已保存密钥；诊断不跟随重定向或回显原服务错误/密钥。

## 任务管理

在「自动化」页点「添加任务」打开弹窗创建任务，或点任务卡「编辑」在同一弹窗里改单次、多次、循环及智能任务，选择投递通道，暂停或恢复未来触发，并按任务查看通知执行记录。弹窗底部「确认」提交、「取消」清空草稿并关闭；提交失败时弹窗保持打开并保留已填内容。

- 修改内容/通道保留原下一触发时间和剩余次数；修改定时规则重算计划。
- 触发时间由界面换算成确定值提交：单次走 `delayMinutes`（快捷项）或 `when`（日期时间选择器，含时区），
  循环走 `scheduleRule`（结构化规则，后端编译成 cron 并保留该规则用于回填），只有切到
  「直接写 cron」才提交 `every`。`in` 保留给小五的自然语言入口。
- 暂停持久化且不触发；恢复过去的单次立即补触发，多次跳到下一未来锚点，循环计算下一未来时刻。
- 编辑、暂停或取消只影响未来安排；已入队/正在处理的执行保留原记录。
- 待办关联任务的内容/时间由待办页管理，任务页不能直接修改其定义，暂停/恢复仍可使用。
- `update_task`、`pause_task`、`resume_task` 和 `update_todo` 已注册为模型工具；获取 ID 和原定义后再操作。

## 待办截止时间与关联提醒

在「待办」页设置截止时间和独立的提醒时间。截止时间用于逾期显示，本身不自动打扰；填写提醒时间才创建关联任务，且提醒不能晚于截止时间。

修改内容/时间会替换关联提醒代际；完成或删除待办取消未来提醒，重新打开可恢复仍在未来的提醒。任务执行和待发送重试都会检查关联是否有效，过期代际或已完成事项不再继续投递。

`todos.json` 是关联的源事实，保存成功后同步任务文件。同步失败会明确显示“待办已保存但提醒同步失败”，阻止错误提醒，并提供恢复同步按钮；修复存储后重试或重启可以幂等清除旧任务、补建缺失任务。不会把跨两文件的失败说成完全成功。

## 通知、已读与延后

通知页和导航显示未读数；标记已读后状态跨重启保留。普通通知可安排10分钟后提醒，新任务保留原通道并记录原通知关系，重复请求复用已安排的延后任务。关联待办通知统一从待办页调整提醒时间。

点击「开启系统通知」才申请系统权限。浏览器不支持或权限被拒时，通知中心继续可用。浏览器页面关闭后不能继续轮询；需要持续后台提醒时使用桌面驻留或已配置外部通知通道。

桌面版关闭主窗口会隐藏到托盘，内核继续运行；点击托盘显示 Friday，再点击托盘“退出 Friday”或系统退出菜单才结束进程。macOS 通知检查实际系统授权和系统接受回调；失败不宣称系统送达。Linux/Windows 已实现对应代码，但本轮未在这些桌面系统运行验收。

桌面通知只允许当前主窗口与内核准确来源显式开启；未启用不主动请求权限或发系统消息。记录保存在 `desktop-notifications.json`，跨重启去重；通知转交失败保留网页通知记录。

隔离桌面验证可使用绝对目录变量 `FRIDAY_DESKTOP_DATA_DIR`，默认仍采用系统配置目录/Friday；不要为测试覆盖系统 HOME。

## 新增接口

响应与现有接口一致使用 `body` 包装，除设置状态及受控初始化外需要登录（Bearer token）。

| 方法与路径 | 行为 |
|---|---|
| `GET /api/setup/status` | 首次账号/模型要求、本机初始化是否允许；不返回凭据 |
| `POST /api/setup` | 受控本机一次性初始化，成功签发登录 token |
| `POST /api/provider/test` | 文本与可选图片输入诊断，不保存配置 |
| `PUT /api/tasks/:id` | 完整替换未来任务定义，参数同创建任务：触发方式 `in`/`when`/`delayMinutes`/`every`/`scheduleRule` 五选一（互斥，冲突时返回点名双方的错误） |
| `POST /api/tasks/:id/pause`、`resume` | 暂停/恢复未来触发 |
| `PUT /api/entries/:id` | 替换文本、`dueAt`、`remindAt`；时间使用带时区RFC3339，null移除；笔记条目忽略并清空时间 |
| `POST /api/entries/reconcile` | 恢复待办与任务文件同步 |
| `GET /api/notifications?taskId=...` | 按任务过滤后返回最新100条；未读统计仍是全局 |
| `POST /api/notifications/:id/read` | 持久化已读 |
| `POST /api/notifications/:id/snooze` | `minutes` 为1分钟至7天；普通通知幂等延后 |

## 自动验收与发布边界

```bash
go test -race ./...
go vet ./...
cd web
npm ci
npm run check
npm run build
cd ..
go build -o /tmp/friday ./cmd/robot
python3 scripts/p0_smoke.py --binary /tmp/friday
```

本地集成脚本使用标准库假模型和独立临时数据，覆盖首次设置、模型诊断/工具/流式对话、任务编辑/暂停、待办关联、通知已读/延后及重启恢复，不联系真实外部服务。

`.github/workflows/check.yml` 执行 Go、前端检查、构建产物一致性及本地模拟验收；远程运行前须配置只读依赖仓库的 `CAPYFLOW_MODULES_TOKEN`。工作流的存在不代表远程检查已经执行。

Docker Hub 本轮网络超时，完整 Dockerfile 构建未完成。已使用缓存的 Alpine 3.23 验证静态 Linux 二进制、真实入口、非root运行、默认端口映射及重启持久化；这不替代生产 Alpine 3.22 镜像构建。macOS 应用包为本地未签名调试产物；签名、公证和跨平台安装验收仍需发布环境。
