01

工作区信任层

  • 每轮开始前自动快照：git 仓库用无侵入基线加未跟踪备份，非 git 目录用带上限的副本，失败会明说“只能看不能还原”。
  • 时间线标出「本轮改动 N 个文件」，逐文件看 diff；工具行能直接跳到对应文件。
  • 一键还原本轮：先整轮预检，本轮之后又被改过、删除或重建的文件拒绝还原，并点名是哪个。
轮前快照无损 · 无侵入
一键还原先预检再动手
02

审批与运行

  • 工作区可选默认审批档位：每次都问（默认）/ 只读 / 自动。agent 没有等价档时只朝更保守的方向退一档，并在会话头部标出实际落点（例如 codex 的 workspace-write）。
  • 新增「运行」页：轮次、排队、计划、目标、定时任务、待审批与失败一屏可见，可停止、批准、重试或跳回会话。
  • 并发跑满时消息标成排队中并写明占用比，可以「取消排队」；空闲连接会让位，不再让人干等十分钟。
实际落点不假装有 ask
排队可见可取消 · 会让人
03

会话与记忆

  • 上下文交接：水位快满时「总结并新开」，摘要随下一轮下发，旧会话原样保留可查。
  • 工作区项目记忆：按工作区共享的约定页，回答行可一键记入；新会话首轮自动带上，跨 codex / opencode 共用。
  • 超时预算分三段且可按 agent 调：握手、建会话、单轮；npx 型命令首次拉起自动放宽。
  • agent 收了消息 30 秒没有任何动静会先给提示，不再让人对着安静界面猜它死没死。
项目记忆按工作区沉淀
